# 中证A500估值监控系统 V4.0

## 系统简介

每日自动拉取中证A500指数（000510）及沪深300、创业板指等多个指数的PE/PB数据，计算历史分位（近10年/自基日双基准），通过微信推送日报+警报，并生成交互式网站看板。

**核心功能**：
- 📊 估值监控（PE/PB/ERP分位）
- 💰 持仓追踪（加密存储）
- 💵 资金仓位管理
- 📈 分批买入/卖出策略
- 📱 交互式网站看板
- 🔔 微信多时段推送
